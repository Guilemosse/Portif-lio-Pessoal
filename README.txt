PORTFÓLIO PESSOAL

Como abrir:
1. Extraia o ZIP.
2. Abra index.html em seu navegador.

Como personalizar:
- No index.html, altere "Seu Nome" para o seu nome.
- Troque os textos do Sobre e dos Projetos por informações reais.
- Atualize o e-mail no link mailto: e o endereço do GitHub.
- O visual está no style.css; o menu mobile está no script.js.

Tecnologias: HTML, CSS e JavaScript puro. Não utiliza framework.
A fonte do Google Fonts requer internet; caso não esteja disponível, o navegador utilizará fontes alternativas.
